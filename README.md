# 🐾 Paws & Parcel

**Roblox 기반 소포 접수·보관·수령 시뮬레이션 게임**  
*개발 중 (In Development)*

## 프로젝트 소개

**Paws & Parcel**은 우체국을 배경으로 손님의 소포를 접수하고, 보관 공간에 쌓아 두었다가 수령하러 온 손님에게 전달하는 게임입니다.

소포의 크기와 보관 공간을 고려해 물건을 배치하고, 여러 소포가 쌓인 상태에서도 자연스럽게 집고 옮길 수 있는 시스템을 만드는 데 집중하고 있습니다.

## 주요 구현 기능

### 📦 소포 배치 및 적층
- **0.5 스터드 단위 그리드**와 높이 정보를 이용한 배치 판정
- 소포 크기·회전·공간 점유·충돌을 고려한 배치 위치 계산
- 소포의 위·아래 관계를 관리하고, 중간 소포를 집으면 그 위에 놓인 소포까지 함께 이동
- 묶음 이동 시 소포 간 상대 위치를 유지하고 물리적 연결을 관리

### 🔒 서버 중심 검증
- 클라이언트는 입력과 배치 미리보기를, 서버는 최종 배치·집기·전달 판정을 담당
- 소포 소지 상태, 플레이어와의 거리, 요청 데이터 및 배치 가능 여부 검증
- 요청 빈도 제한 및 작업 실패 시 배치·물리 상태 복원 처리

### 🐶 손님 AI 및 소포 업무
- 경로 탐색 기반 손님 이동과 카운터 자리 점유 관리
- 소포를 맡기는 **Dropoff** / 찾으러 오는 **Pickup** 업무 분기
- 수령인·소포 코드 기반 소포 관리 및 고객별 여러 소포 요청 처리
- 일부 소포만 전달된 경우 남은 수량을 관리하고, 전달이 완료되면 손님 퇴장

### 🖱️ 조작 및 시각 피드백
- 배치 가능 위치를 보여주는 미리보기 및 대상 하이라이트
- 회전과 소포 묶음 소지 상태에 따른 시각 처리

## 기본 조작

| 입력 | 동작 |
| --- | --- |
| 마우스 왼쪽 클릭 | 소포 집기 / 배치 / 손님에게 전달 |
| `R` | 소지한 소포 회전 |
| `Q` | 소지한 소포 내려놓기 |

> 조작 및 게임 규칙은 개발 과정에서 변경될 수 있습니다.

## 코드 구조

```text
src/
├── client/
│   ├── init.client.luau       # 플레이어 입력 및 배치 미리보기 요청
│   ├── CarryController.luau   # 소지 상태 시각 처리
│   ├── PlacementPreview.luau  # 배치 프리뷰
│   └── RaycastUtil.luau       # 마우스 대상 감지
├── server/
│   ├── init.server.luau       # 손님 생성 및 초기화
│   ├── CustomerAI.luau        # 손님 이동과 업무 요청
│   ├── ParcelManager.luau     # 소포 정보와 접수·수령 관리
│   ├── ParcelConfig.luau      # 소포 설정
│   ├── Placement.server.luau  # 서버 요청 처리 및 검증
│   ├── PlacementState.luau    # 그리드 점유·적층 관계 관리
│   └── ParcelAssembly.luau   # 소포 묶음 및 물리 연결 관리
└── shared/
    ├── GridConfig.luau       # 그리드·검증 제한 설정
    ├── ParcelGeometry.luau   # 소포 크기 및 위치 계산
    ├── PlaceItem.luau        # 배치 아이템 회전 상태
    └── PlacementMath.luau    # 그리드 셀 계산
```

## 설계 방향

**클라이언트의 입력을 서버에서 다시 검증하는 구조**를 중심으로 구현하고 있습니다. 또한 논리적인 배치·적층 상태(`PlacementState`)와 실제 소포의 물리적 연결(`ParcelAssembly`)을 분리하여 관리합니다.

단순히 소포 하나를 놓는 기능에서 끝나지 않고, 여러 소포를 쌓고 집는 상황까지 고려해 기능을 확장하고 있습니다.

## 실행 관련 안내

이 저장소의 `src` 코드는 **Roblox Studio의 맵·모델·에셋이 있어야 동작하는 게임 로직**입니다. 소스 파일만으로는 게임을 바로 실행할 수 없습니다.

현재 제공된 소스에는 Studio 프로젝트 파일이나 전체 에셋, 프로젝트 동기화 설정이 포함되어 있지 않아 별도의 설치·실행 절차를 안내하지 않습니다.
